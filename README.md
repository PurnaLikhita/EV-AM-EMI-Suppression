# EV AM EMI Suppression Project

**Adaptive EMI suppression for AM radio in electric vehicles** — VVIT ECE final-year project — Team A6 — Guide: Dr. K. Vijay Vardhan

This repository contains MATLAB simulations for LMS, NLMS, and RLS adaptive EMI suppression, a measured-source demonstration based on charger-voltage data, the saved MATLAB outputs, and Simulink construction helpers.

## Run the project in MATLAB

1. Open MATLAB and set **Current Folder** to the repository root: the folder containing `main.m`, `run_measured_demo.m`, and `data/`.
2. In the Command Window, run the scripts below **one at a time**:

```matlab
main
run_measured_demo
compare_algorithms
```

`main` runs the required synthetic LMS experiment. `run_measured_demo` runs the measured-source simulation. `compare_algorithms` is an optional LMS/NLMS/RLS comparison. Each command is a script name: do not call `config()` or use `main(cfg)`; this project has no `config.m` function.

The measured CSV is already included at `data/EVCharger_Lab_Data_V1.CSV`; `load_emi_dataset.m` is the loader. The scripts save their tables, MATLAB data, and figures under `results/`.

| Script | Main output files |
|---|---|
| `main` | `results/final_results_table.csv`, `results/final_results.mat`, figures in `results/` |
| `run_measured_demo` | `results/measured_source_simulation/metrics.csv`, `run_data.mat`, `experiment_log.txt`, comparison figure |
| `compare_algorithms` | `results/algorithm_comparison_table.csv`, `algorithm_comparison.mat`, comparison figure |

No additional MATLAB toolboxes were needed for these runs. The repository does not contain a compiled `.slx` model; see `simulink/README_SIMULINK.md` for instructions and helper code to build it.

## Model assumptions and limitations

- The synthetic experiment uses a scaled carrier (`Fs = 100 kHz`, `fc = 10 kHz`) to keep computation manageable; this is not an RF-accurate AM-band receiver model.
- Synthetic EMI is constructed from assumed switching harmonics, an envelope, an assumed coupling path, and broadband noise; it is not measured EV EMI.
- The adaptive canceller is given a reference correlated with the EMI source, representing access to an inverter/PWM synchronization tap.
- Noise levels and coupling are controlled by the simulation. Results should not be presented as field measurements or proof of vehicle-level performance.
- The measured-source CSV is from SupraEMI (2021), *Waveform Data -EVCharger_Lab* (Version V1), Zenodo: https://doi.org/10.5281/zenodo.4431657.

## Repository structure

- `main.m` — required synthetic LMS pipeline.
- `run_measured_demo.m` — measured-source offline simulation and validation-tuned NLMS.
- `compare_algorithms.m` — optional synthetic LMS/NLMS/RLS comparison.
- `*_filter.m`, `generate_*.m`, and `calculate_*.m` — signal generation, adaptive filters, metrics, and plotting helpers.
- `data/` — included charger-voltage CSV.
- `results/` — regenerated tables, MAT files, logs, and figures.
- `simulink/` — helper scripts and block-by-block build instructions.
